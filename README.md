## Overview
This repository is a collection of projects and solutions developed during hackathons and academic challenges. It includes systems programming labs, security challenges, web development projects, and competitive programming solutions.

## Projects

### CS:APP Labs
- **Description**: Solutions and materials for the CS:APP Data Lab and Bomb Lab, focusing on systems programming, C, bit manipulation, and reverse engineering.
- **Link**: [csapp-labs](https://github.com/patricksferraz/hackathon/tree/all/csapp-labs)

### ENSI 2019
- **Description**: Security and pentesting challenges, including CSIRT incident response, learning (mobile dev), and rootme (blackbox pentest).
- **Link**: [ensi-2019](https://github.com/patricksferraz/hackathon/tree/all/ensi-2019)

### Mata Atlântica 2017
- **Description**: A web project focused on environmental awareness and reporting, built with PHP and JavaScript.
- **Link**: [mata-atlantica-2017](https://github.com/patricksferraz/hackathon/tree/all/mata-atlantica-2017)

### Time Manager API
- **Description**: A Node.js REST API for managing time slots, with detailed usage instructions and endpoints.
- **Link**: [time-manager-api](https://github.com/patricksferraz/hackathon/tree/all/time-manager-api)

### URI Online Answers
- **Description**: Python solutions to URI Online Judge problems, organized by problem number and type.
- **Link**: [urionline-answers](https://github.com/patricksferraz/hackathon/tree/all/urionline-answers)
